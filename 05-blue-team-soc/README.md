# Blue Team and SOC Practice

## Learning path
- [ ] Understand logs and timestamps
- [ ] Learn basic Linux authentication and system logs
- [ ] Identify normal vs. suspicious activity in sample data
- [ ] Practice alert triage with intentionally provided training data
- [ ] Write a short incident timeline
- [ ] Document findings, confidence, and recommended next steps

Use synthetic logs, local lab data, or authorized training platforms. Redact sensitive details from all published evidence.
