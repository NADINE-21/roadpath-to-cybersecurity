# Linux Command-Line Fundamentals

## Goal
Build confidence navigating the filesystem and using basic Linux commands in the Kali VM.

## Topics
- [ ] Identity and current directory: `whoami`, `pwd`
- [ ] List files: `ls`, `ls -la`
- [ ] Navigate: `cd`
- [ ] Create files and directories: `touch`, `mkdir`
- [ ] Read files: `cat`, `less`, `head`, `tail`
- [ ] Copy and move: `cp`, `mv`
- [ ] Remove files carefully: `rm`
- [ ] Help: `man`, `command --help`
- [ ] Users and permissions

## Practice lab
Use only a test directory created for this exercise. Avoid experimenting with destructive commands on system files.
